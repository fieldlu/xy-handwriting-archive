# 小雅作业华为笔记导出

> **打开作业页面，题目自动变手写。** 自动捕获作业题目与标准答案，一键生成笔顺级仿真手写笔记，导出 **.hinote（导入华为平板继续写）/ PDF / JPG**。

GitHub 镜像：[fieldlu/xy-handwriting-archive](https://github.com/fieldlu/xy-handwriting-archive)（与 Gitee 主仓库双端同步更新，内容一致）

本脚本是原「小雅辅助工具 · 笔记版手写导出」功能的完整独立版（自 v3.7.4.5 拆分），不依赖小雅辅助工具，可单独安装使用。

---

## 功能

- ✍️ **笔顺级仿真手写**：笔顺中心线引擎（Make Me a Hanzi 常用字库），笔画顺序自然，不是简单换字体
- 🧠 **全字符覆盖**：库外字与标点走字体栅格 + 骨架细化兜底，任何内容都能写
- 📝 **Markdown 转手写**：标题分级 / 列表 / 代码块 / 引用 / 分割线，行内标记剥除不残留星号，源文件空行保留为段落间距
- ∑ **数学公式手写体化**：`$..$` / `$$..$$` 公式 LaTeX→Unicode 线性化（θ∫√≤、上下标 ²ᵢ、分式 (a)/(b)），与正文统一手写笔迹；映射表外置分发
- 📄 **三面板界面**：📚作业归档 / 📄纯文字 / 📝Markdown 独立切换——纯文字所见即所得零解析
- 📒 **.hinote 导出**：华为笔记格式（纯笔迹），导入华为平板备忘录/笔记接着手写
- 📃 **PDF / JPG 分页**：A4 笔记纸（笔记本横线 + 装订线 + 印刷体页码），150dpi 高清，直接打印
- 📡 **实时捕获作业题目**：先于页面脚本装好请求劫持（fetch + XHR 双通道），平台自发发出的题目请求实时截获，零操作零等待
- 🔄 **自动更新**：脚本管理器自动检查新版本；应用内每 6 小时静默检查一次，面板「↻」按钮随时手动检查（双版本对照 + 更新日志 + 一键前往安装页）
- 💾 **资源外置缓存**：笔顺库与公式映射表本地缓存，仅脚本升级时重新拉取，日常使用零额外流量
- ✅ **内容范围自由勾选**：题目 / 标准答案 / 我的作答，导出前自由组合（选择记忆）
- 🪶 **脚本轻量化**：本体约 186KB，笔顺库（2.3MB）与 LaTeX 映射表后台自动加载（Gitee 分发，仅首次拉取一次）
- 🚀 **纯前端零依赖**：生成全程在浏览器本地完成，无需安装任何软件，数据不出浏览器

## 安装

1. 安装 Tampermonkey 浏览器扩展（或脚本猫）
2. [点击安装小雅作业华为笔记导出（ScriptCat 脚本站）](https://scriptcat.org/scripts/code/8408/%E5%B0%8F%E9%9B%85%E4%BD%9C%E4%B8%9A%E5%8D%8E%E4%B8%BA%E7%AC%94%E8%AE%B0%E5%AF%BC%E5%87%BA.user.js)（备选：[Gitee raw 直装](https://gitee.com/fieldlu/xy-handwriting-archive/raw/main/%E5%B0%8F%E9%9B%85%E4%BD%9C%E4%B8%9A%E5%8D%8E%E4%B8%BA%E7%AC%94%E8%AE%B0%E5%AF%BC%E5%87%BA.user.js)）
3. 打开小雅平台（whut.ai-augmented.com），页面右下角出现「✍️ 手写」悬浮按钮
4. 进入作业/试卷页面，脚本自动捕获题目（面板顶部状态条显示「已捕获 N 题」）

## 使用说明

1. 点击右下角「✍️ 手写」展开面板，顶部三个 Tab 切换：
   - **📚 作业归档**：打开作业/试卷页面自动捕获题目（顶部显示「📡 已捕获 N 题」），勾选导出范围（题目 / 标准答案 / 我的作答）
   - **📄 纯文字**：粘贴任意文字，所见即所得直接转手写
   - **📝 Markdown**：粘贴 Markdown 笔记（支持数学公式 `$..$` / `$$..$$`），自动解析排版
2. 填写文件名（默认：手写归档）
3. 点击「📒 .hinote」/「📄 PDF」/「🖼 图片」导出

导出结果为纯笔迹（不嵌入图片），适合个人复习归档场景。

## 技术说明

- 引擎四模块：hinote 写入器（华为 .hinote 二进制格式，真机验证）/ 文字排版（笔顺中心线 + 骨架兜底）/ A4 笔记纸分页 / JPEG 页 → PDF 合成，全部随脚本内嵌
- 外置资源：笔顺库 xy-hw-db.json（Make Me a Hanzi 常用字子集，1024 坐标系，2.3MB）+ 公式映射表 xy-hw-tex.json（希腊字母/运算符/上下标），GM 特权拉取 + 版本缓存 + 预取，仅首次使用前联网一次
- Markdown 解析器轻量自研（块级解析 + 行内标记剥除），公式走 LaTeX→Unicode 线性化并入正文，无 MathJax 依赖
- 印刷体页码走字体栅格骨架化，与手写笔迹视觉统一
- 控制台调试句柄：`XyHandwriting.*` 可直接调用引擎各模块
